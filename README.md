# Portfolio Website

Welcome to my personal portfolio website! This is a modern, responsive portfolio built with HTML, CSS, and JavaScript.

## Features

✨ **Modern Design** - Clean and elegant dark theme with gradient accents

📱 **Responsive** - Works perfectly on desktop, tablet, and mobile devices

🎨 **Smooth Animations** - Engaging transitions and animations throughout

⚡ **Fast & Lightweight** - No heavy frameworks, pure vanilla web technologies

🔗 **Easy Navigation** - Smooth scrolling and intuitive navigation menu

## Sections

- **Home** - Hero section with introduction
- **About** - About me information
- **Experience** - Work experience and timeline
- **Skills** - Technical skills and competencies
- **Projects** - Portfolio of projects
- **Contact** - Get in touch section

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Gradients)
- Vanilla JavaScript

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize the content with your own information

## Customization

Edit the following files to personalize your portfolio:

- **index.html** - Update your information, projects, and skills
- **styles.css** - Modify colors, fonts, and layout
- **script.js** - Add custom JavaScript functionality

### Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #a855f7;
    --accent-color: #ec4899;
    --dark-bg: #0f0f1e;
    --darker-bg: #0a0a15;
}
```
